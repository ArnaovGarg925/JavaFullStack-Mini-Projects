# Java OOP Calculator

A Java Swing calculator project demonstrating core Java and OOP concepts.

## Features
- Addition, subtraction, multiplication and division
- Modulus, power, average
- Square, square root and reciprocal
- Positive/negative toggle and backspace
- Memory functions: M+, M-, MR, MC
- Calculation history and clear history
- Basic input and divide-by-zero error handling

## Technologies
- Java
- Java Swing
- Maven
- JUnit

## OOP Concepts
- Encapsulation
- Abstraction
- Interface
- Method-based design

## Run
```bash
mvn clean test
mvn package
```
Then run the generated JAR from the `target` folder.
